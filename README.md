# 프로젝트 명: Sound of Vista

> **한 줄 요약: 5.1채널 입체음향을 활용한 프로젝트**

## Project Overview

본 프로젝트는 입체음향을 통한 힐링 컨텐츠를 제공 위해 개발된 유니티 기반 프로젝트입니다.

현재 저장소는 **유료 에셋 라이선스 보호 및 저작권 준수**를 위해 프로젝트 전체 파일 대신, **소스코드(Scripts)로 공개**되어 있습니다.

* **개발 기간**: 2024.09 ~ 2025.12
* **개발 환경**: Unity 6, C#
* **핵심 기술**: 5.1Channel Audio, Firebase

---

## 🚀 Key Features

* **랜덤 매칭 시스템**: Photon 서버를 활용하여 대기실(Lobby) 내 플레이어 간 빠른 랜덤 매칭 구현
* **RPC 기반 실시간 데이터 동기화**: `[PunRPC]`를 활용하여 플레이어 간 [카드 사용/피격 판정/이동] 등의 이벤트를 0.1초 내외의 지연 시간으로 동기화
* **[핵심 기믹 이름]**: (예: 포인트 앤 풀 이동) 마우스 클릭 지점으로 물리적 가속도를 주어 이동하는 독자적인 이동 시스템 구현
* **[기타 기능]**: 실시간 채팅, 인벤토리 시스템 등
